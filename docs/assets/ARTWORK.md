# Relay Logs artwork

The repository banner and social preview follow the Relay artwork direction used by Relay Chat and Relay Cards. They use the official Relay mark from the organization profile as it is, without redrawing it.

## Banner

`banner.png` uses a 3:1 composition. The left side contains the Relay mark, the product name, and a direct description. The right side depicts the real viewer: the header with the visible levels and the following indicator, log lines with their time, level, source, and message, an error selected with its stack frame below it, a highlighted search match, and the search prompt.

## Social preview

`.github/social-preview.png` recomposes the same interface for a 2:1 thumbnail. The description is removed, and the mark and name are stacked so they stay legible in repository cards.

## Direction

Both images use the shared Relay palette (background `#080B0F`, text `#E8EDF2`, blue `#48A8FF`, orange `#FF8A3D`, red `#FF5C6C`, yellow `#F4C95D`, green `#5DD39E`), monospace interface typography, and restrained terminal borders. The content mirrors what the viewer renders, with no decorative code, robots, or imagery of other products.
